# Настольное приложение

`desktop.py` открывает окно сбора по нишам. Впиши поисковые запросы по одному на строку, укажи число страниц и выбери папку выгрузки. Город по умолчанию — Астана. Приложение использует установленный Chrome или Edge.

Каждый запуск сохраняет четыре Excel-файла и журнал в отдельной папке. В журнале видны ошибки проверки и компании с публичным признаком бота. Если 2ГИС ведёт на стороннюю форму, такая запись считается внешней. Запись, доступную только в мобильном приложении, веб-проверка может пропустить. Сайты и боты определяются по доступным публичным страницам.

## Запуск из проекта

Установи Python 3.12 с Tk и браузер. Из корня проекта запусти:

```sh
python -m pip install -r requirements.txt
python desktop.py
```

## Сборка

В отдельном окружении с зависимостями проекта:

```sh
python -m pip install pyinstaller
python tools/build_desktop.py
```

Сборка создаёт ZIP в `dist`. Распакуй ZIP целиком и запусти `2GIS Niche Search.exe` на Windows или `2GIS Niche Search.app` на Mac. Windows-сборку собирай на Windows. Сборки macOS собирай на Mac с Python нужной архитектуры — arm64 для Apple Silicon или x86_64 для Intel. Скрипт использует локальную подпись macOS. Для передачи подписанного приложения другим пользователям нужна сборка с Developer ID и нотарификацией Apple.

## Как собрать ZIP для Mac с Windows

В репозитории GitHub с включёнными Actions запусти **Actions → Build macOS app → Run workflow**. Сборка выдаёт два готовых ZIP: `2GIS-Niche-Search-macOS-arm64.zip` для Apple Silicon и `2GIS-Niche-Search-macOS-x86_64.zip` для Intel. Скачай нужный архив из результатов запуска и отправь его целиком. Получателю достаточно распаковать ZIP и открыть `2GIS Niche Search.app`. На его Mac нужен Chrome или Edge. Python и зависимости уже входят в сборку.

GitHub Actions использует локальную подпись PyInstaller. Для обычной установки на чужом Mac без предупреждения о неподтверждённом разработчике понадобится Apple Developer ID и нотарификация.
